# Dependencias y recursos

La isla y el logotipo SVG fueron dibujados para este proyecto. No contienen recursos de Doodle Champion Island Games. El terreno, los personajes y los objetos de `game.mjs` son dibujos originales mediante primitivas de Canvas; no se descargaron gráficos, música ni código del juego de referencia.

Open Sans se distribuye localmente para evitar solicitudes a proveedores de fuentes. Sus avisos de licencia están en `app/static/FONT-LICENSE.txt`. Tesseract y `tessdata_fast` usan Apache-2.0; el instalador fija la versión 4.1.0 y verifica SHA-256 del modelo de español.

PyMuPDF/MuPDF tiene licencia AGPL y alternativa comercial. Antes de distribuir un producto propietario, elegir el cumplimiento de AGPL, una licencia comercial o sustituir el extractor PDF por una alternativa compatible con el modelo de distribución. No se ha comprado licencia ni decidido la licencia comercial del proyecto.

Las versiones transitivas se registran en `uv.lock`. Revisar las licencias y actualizaciones de las dependencias al publicar. Los servicios de IA tienen condiciones separadas de las bibliotecas de software.
